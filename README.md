# Magpie 鲸鲸余额挂件

一个常驻桌面的悬浮挂件，基于 [Magpie](https://usemagpie.ai) 本机网关，实时显示各供应商（中转站）的**账户余额**与**用量/花费**；每轮对话结束后还会就地弹出这一轮花了多少钱。

它只**读取**本机 Magpie 的缓存接口（`/v1/magpie/quotas` 与 `/v1/magpie/usage`），不拦截、不代理、不修改你的任何请求——纯只读的旁观者。

## 前置条件（务必先在 Magpie 里配好，否则挂件没数据可显示）

挂件本身不连上游、不算钱，所有数据都来自 Magpie。使用前请确认你的 Magpie 已经：

1. **接入了中转站供应商（Provider）**：在 Magpie 里添加你实际在用的中转站/API 供应商和密钥，并能正常对话。
2. **配置了模型价格**：给每个模型填好单价（输入/输出每百万 token 的价格等）。Magpie 靠这个价格表把 usage 换算成金额；**没填价格的模型，其花费会显示为「未定价」，也不会计入费用**。这一步直接决定「本次对话花了多少钱」准不准。
3. **能查到账户余额**：供应商需支持并在 Magpie 里启用了**余额查询**（quotas）。余额来自 Magpie 向上游查询的结果；有些中转站不提供余额接口，这种供应商只会有用量、没有余额。
4. **本机网关可访问**：挂件默认连 `http://127.0.0.1:3425`（Magpie 本机网关默认地址），可用环境变量 `MAGPIE_GATEWAY` 覆盖。

> 一句话：**价格填全 → 费用准；余额接口通 → 余额显示得出来。**

## 功能

### 1. 桌面常驻余额气泡
- 右下角常驻一只小鲸，气泡上显示**当前供应商的账户余额**（按你为该供应商设定的币种显示，见下）。
- 余额会随定时轮询自动更新；低于阈值（换算后人民币 < ¥5）时气泡变红提醒。
- 位置可拖动，拖动后的位置会被记住。

### 2. 每轮对话后显示本次消耗（核心功能）
- 挂件会盯住 Magpie 的 `usage.jsonl`，自动识别「一轮对话什么时候结束」（流式请求收到 `end_turn`/`stop`/`completed` 等结束标记；Codex 这类不回 stop 的则等会话静默一段时间再判定）。
- 每轮结束时，用 Magpie 按你填的价格算好的**该会话累计费用**，减去本轮开始前的值，得到**这一轮的真实花费**，然后：
  - 在气泡旁弹出「本次 ¥x.xx」的提示（停留时长默认 60 秒，可在 config 里调 `toastSec`）；
  - 同一对话在提示消失前又结束一次（子代理、连续 stop 等），会**接着累加**而非另起一轮；
  - 攒下的记录汇总到详情页的「最近对话」里（保留最近 12 条）。
- 余额读的是 Magpie 的缓存，不打上游；但为了费用/余额及时，对话结束会**节流地**触发一次上游余额刷新（见下文"刷新节奏"）。

### 3. 详情页（点气泡展开）
点击气泡弹出详情卡片，包含：
- **顶部**：当前供应商名 + 余额；右侧三个按钮——币种图标（见下）、立即刷新、关闭。
- **账户行**：供应商下若有多账户/多 key，逐个列出。
- **三个标签页**：
  - **今日**：今天的调用次数、输入/输出/缓存 token、总花费，并按模型细分（列出最贵的模型）。
  - **近 7 天**：同上口径的一周汇总。
  - **最近对话**：每一轮对话的费用记录（会话标题、所用 agent、供应商、本轮金额）。

### 4. 多供应商（中转站）支持与切换
- 支持同时存在多个供应商，各家的余额/用量分别显示。
- **左键点详情里的供应商**可切换当前查看的供应商；也可在**托盘右键菜单 → 供应商**里选。
- **中键点气泡**：临时按顺序切到下一个能读到余额的供应商（松手/离开后自动交还给「自动」模式）。
- **自动模式（默认）**：跟随你「最近实际在用的 API」——读 `usage.jsonl` 里最后一条对话请求所属的供应商，正在用哪家就显示哪家。

### 5. 币种 / 汇率（按供应商独立）
可对**每个供应商单独**指定它实际计费用的是人民币还是美元，**忽略供应商回传的币种符号**：
- 指定 **人民币 (¥)**：余额数值原样以 `¥` 显示。
- 指定 **美元 ($)**：数值当作美元，按你填的汇率换算成人民币，仍以 `¥` 显示。
- 详情页右上角、刷新按钮**左侧**有一个 `¥` / `$` 小图标显示当前供应商的币种：
  - **左键**：在人民币/美元之间切换；
  - **右键**：手动输入/更新美元兑人民币汇率（不联网，纯手动）。
- 各供应商的币种与汇率各自独立保存，互不影响；所有金额统一按人民币 `¥` 呈现，方便横向对比。

### 6. 托盘与设置
托盘图标悬停显示当前供应商余额；右键菜单提供：
- **供应商**：切自动 / 钉死某一家；
- **大小**：60% / 80% / 100% / 120%；
- **镜像翻转**：鲸鱼娘换到另一侧；
- **立即刷新余额**；
- **开机自启**；
- **显示 / 隐藏气泡**；
- **退出**。

### 7. 刷新节奏（防止把上游查爆）
- 读缓存轮询：默认每 10 秒一次（`pollSec`）。
- 定时上游重查余额：默认每 60 分钟（`refreshMin`）；对话结束另触发，但两次之间至少隔 30 分钟（`turnRefreshMin`），且每个供应商都有最小间隔与每日次数上限（默认每天 ≤150 次），手动刷新不受此限。

## 下载与使用

到 [Releases](https://github.com/BBBBBSM/magpie-balance-bubble/releases) 下载 `Magpie-Whale-Bubble-*-portable.exe`（免安装绿色版），双击即可运行。

> Windows 首次运行可能弹 SmartScreen 提示（本包未做代码签名），点「更多信息 → 仍要运行」即可。

## 从源码运行 / 打包

```sh
npm install
npm start        # 直接运行
npm run dist     # 打包绿色版到 dist/
```
